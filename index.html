Clyde Palmer - mail and sheets tools

This is a small set of scripts I run for my own work. They use my own Google account, and nobody else's.

When I sign in, the scripts can:

  • read my Gmail, so they can find the emails I need to reply to;
  • create draft replies and send the daily rate-loading report to the clients I work with, from my own mailbox;
  • read and update Google Sheets that I own or that have been shared with me;
  • act as my personal assistant: file my mail into labels, keep my inbox tidy, read my calendars to find free time, add reminders, and email a daily briefing to me.

They don't delete email, and they don't touch anything outside my own account.

How the information is handled is set out in the privacy policy.
